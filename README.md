# Quiz Time! — Jeopardy Technocamp 2026

Papan quiz Jeopardy statis (HTML/CSS/JS). Klik kotak poin untuk menampilkan soal.

- `index.html` — papan & layar soal
- `soal.js` — daftar soal (tanpa jawaban)
- `assets/board.jpg` — gambar papan

Setelah soal dibacakan, klik **KEMBALI KE PAPAN** (atau `Esc`). Terjawab atau tidak, poin soal itu hilang dari papan. `F` layar penuh. Kotak yang poinnya sudah hilang tetap tersimpan meski halaman di-reload (disimpan di browser). Untuk memunculkan semua kotak lagi, klik **logo SU** di bagian atas papan, atau tombol **RESET PAPAN** (muncul saat mouse di pojok kanan bawah).

Deploy: import repo ini di Vercel (tanpa build, framework "Other").
