# Quiz Time! — Jeopardy Technocamp 2026

Papan quiz Jeopardy statis (HTML/CSS/JS). Klik kotak poin untuk menampilkan soal.

- `index.html` — papan & layar soal
- `soal.js` — daftar soal (tanpa jawaban)
- `assets/board.jpg` — gambar papan

Shortcut: `F` layar penuh, `Esc` kembali ke papan. Tombol **RESET PAPAN** muncul saat mouse di pojok kanan bawah.

Deploy: import repo ini di Vercel (tanpa build, framework "Other").
